Ollama with `qwen3:4b`); no images are generated by the project.

|---|---|
| `main-comparison.png` | Scenario selected, six-agent comparison table |
| `scenario-a.png` | Scenario A comparison |
| `scenario-b.png` | Scenario B comparison |
| `scenario-c.png` | Scenario C comparison |
| `model-based-memory.png` | Model-Based memory demonstration (two observations) |
| `utility-ranking.png` | Utility-Based expander with the ranking table |
| `learning-before.png` | Learning demonstration before any feedback |
| `learning-after.png` | Learning demonstration after four recorded failures |
| `llm-tool-calling.png` | LLM Agent expander: runtime, model, two or more tool calls, source IDs, validation |
| `tests.png` | Terminal showing the offline test result |

For `llm-tool-calling.png`, at least two distinct tools must be visible.
